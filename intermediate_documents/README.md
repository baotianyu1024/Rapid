# Revision working documents

These are snapshots of the intermediate reports, response drafts and small
result tables produced during the revision experiments. They are preserved for
auditing decisions and figures; an older draft or CSV is not automatically a
current manuscript claim.

| Directory | Contents |
|---|---|
| `responses/` | English and Chinese response drafts, generated PDFs and their three SVG figures |
| `reports/` | Experiment notes, diagnostics, model/communication checks and T-series records |
| `results/` | Small CSV summaries consumed by the response and experiment scripts |

Start with `responses/Response_English_MetaReview_First.md` for the organized
meta-review response and `responses/Response_中文审阅版_MetaReview优先.md` for its
Chinese reading copy. Use `../revision/README.md` for the execution order, commands,
input requirements and validation checks behind the measurements.

The T-series reduced-size GPU attempts are retained as intermediate records;
the response uses official T-series single-part communication comparisons
instead of presenting those reduced-size throughput runs as full official
end-to-end results. Raw datasets, logs, model checkpoints, reviewer source
PDFs, local environment files and credentials are excluded from this directory.
